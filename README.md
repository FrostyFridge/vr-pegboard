# vr pegboard

Some pegboard mounts for vr equipment.

- index controllers
- index headset
- vive tracker (fits 2.0 and 3.0)

These are designed to use [pegboard screw anchors](https://3dprints.electronsmith.com/pegboard-screw-anchors/) instead of pegboard hooks for a more firm connection that doesn't wobble.

I pad out the surfaces and cups with 1mm neoprene foam. If you don't want to do that be aware that the fit will be looser as a result.

I use magnetic adapters, set into place on the mounts with hot glue.

- [magnetic usb c adapters (amazon)](https://www.amazon.com/dp/B0DWY23G9Y)
- [micro usb magnetic tips (amazon)](https://www.amazon.com/dp/B0BPR7VKZY)


have fun :)
